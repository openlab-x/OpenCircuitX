# and_gate (Yosys synthesis + Icarus simulation)

The same 2-input AND gate as `icarus/and_gate`. This copy also has a testbench, so the one project demonstrates both FPGA synthesis (Yosys) and simulation (Icarus) side by side.

## Requirements

`yosys` and `iverilog`/`vvp` on your PATH, or configured under Tools > Settings. All three ship with [OSS CAD Suite](https://github.com/YosysHQ/oss-cad-suite-build).

## Synthesize (Yosys)

1. **Open Project** and select `and_gate.ocxproj`.
2. Open `and_gate.v`.
3. **Tools > FPGA > Synthesize** (or **F9**), enter `and_gate` as the top-level module, pick a board (iCEBreaker is fine, this design doesn't touch any board-specific pins).
4. OpenCircuitX drives Yosys itself - no `.ys` script needed by hand. It writes `and_gate.json` next to the source and prints a LUT/DFF/BRAM usage report in the Output panel.

There's no `.pcf` constraint file here, so this stops at synthesis. Place & route (`Tools > FPGA > Place & Route`) needs pin constraints for a real board and isn't part of this example.

**Synthesis never produces a waveform.** Yosys turns RTL into gates; there's no simulation involved in that step at all. See below for that.

## Simulate (Icarus)

1. Open `tb_and_gate.v`.
2. Press **F6** (Run Simulation).
3. The Waveform tab opens automatically. `y` should go high only in the last 20 ns window, when both `a` and `b` are 1.

## Why RTL View shows nothing here

RTL View parses VHDL only. It also doesn't read the Yosys JSON netlist from the synthesis step above, so synthesis output and the schematic viewer are currently two disconnected features. Tracked as a planned feature (Yosys JSON netlist import), not a bug.

## Files

- `and_gate.v` - the design
- `tb_and_gate.v` - testbench with real stimulus and a `$dumpfile`/`$dumpvars` block (required for Icarus to produce a `.vcd` at all - it has no `--vcd` flag like GHDL does)
- `and_gate.ocxproj` - project file, `[Build] TopEntity=and_gate` and `[Simulation] TopEntity=tb_and_gate` pre-filled

`and_gate.json` (the synthesis output) isn't committed - it's regenerated by the Synthesize step above.
